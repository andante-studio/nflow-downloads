# N.FLOW Android 다운로드

N.FLOW는 엔플라잉 이승협의 생일을 기념한 비공식 팬게임입니다.

이 공개 저장소는 Android APK 배포 전용입니다. 게임·웹 소스, 개인 음원, 플레이 기록 및 서명키는 포함하지 않습니다.

## 설치·플레이 테스트

현재 배포는 정식 공개 전 설치·플레이 확인을 위한 **테스트용 prerelease**입니다.

- [테스트 APK 다운로드 — N.FLOW.apk](https://github.com/andante-studio/nflow-downloads/releases/download/v1.0-test.1/N.FLOW.apk)
- [N.FLOW 홈페이지](https://for-seunghyub.pages.dev/)
- 앱 버전: 1.0 (versionCode 1)
- 지원 환경: Android 8.0 이상, ARM64
- 음원은 제공하지 않습니다. 공식 음원 사이트에서 구매한 MP3 / WAV / FLAC 파일을 사용해주세요.

다운로드한 APK를 Android에서 열고 기기의 설치 안내를 확인해주세요. 기존 앱과 서명이 다르면 덮어쓰기가 불가능할 수 있습니다. 기존 데이터를 삭제하지 말고 제작자에게 확인해주세요.

파일의 SHA-256과 테스트 안내는 해당 Release에 기록합니다.
